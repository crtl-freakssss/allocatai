## E2E Lifecycle Flow

1. **User Action**: Submit new proposal form and attach PDF document.
2. **Backend Execution**:
   - `POST /api/v1/proposals` $\to$ Returns proposal (`PRO-0019`).
   - `POST /api/v1/proposals/PRO-0019/documents` $\to$ Uploads PDF bytes, computes SHA-256 (`DOC-0019`).
   - `POST /api/v1/proposals/PRO-0019/extract` $\to$ `AIExtractor` parses text, constructs canonical `Project` (`PRJ-0019`).
3. **Portfolio Optimization**:
   - User adjusts budget slider (e.g. ₹20 Crore $\to$ `20000000000` paise) and triggers `POST /api/v1/optimization/runs`.
   - `MILPOptimizerFormulation` (`scipy-milp-v1`) computes optimal fund allocation vector.
   - `AllocationTable` displays exact allocated vs. unallocated paise formatted cleanly in Indian Rupees ($\text{₹}$).
4. **Audit Trail**:
   - `AuditTimeline` displays immutable `OPTIMIZATION_COMPLETED` audit event with request tracking metadata.
